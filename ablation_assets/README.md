# Fixed-CFG ablation assets

Minimal HF run 4 DSL~1 artifacts for laptop fixed-CFG ablation:

- `cfg/cfg_output_1.json`
- `grids/*_dsl1_*` (terminal-function test grids)
- `function_specific_prompts/*dsl1*`
- `functions_generated/*dsl1*`
- `status/dsl1/file_generation/status`

Unpack at repo root:

```bash
cd ~/Desktop/DSL_Generator
tar -xzf ablation_assets/run4_dsl1.tar.gz
```

Or download from GitHub (see `docs/ABLATION_LAPTOP.md`).
