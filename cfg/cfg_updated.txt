- **PICKUP_IF_ADJACENT(args):** Picks up the specified `PRIMITIVE` only if the agent is on a free cell adjacent to the resource and is facing it.  
- **USE_TOOL(args):** Uses the indicated `TOOL` on the cell directly in front of the agent.  
- **CRAFT(args):** Crafts the specified `ITEM` at the given `WORKSHOP`, assuming all ingredients are already in the inventory.  
- **CRAFT_IF_READY(args):** Crafts the `ITEM` at the `WORKSHOP` **only if** the required ingredients are present; otherwise the statement does nothing.  
- **GO_TO(args):** Navigates the agent to a position adjacent to the `TARGET` (either a primitive resource or a workshop) and orients it toward the target, handling all necessary `TURN`/`MOVE` steps internally.

The grammar describes a small imperative language for an autonomous agent that can move, manipulate items, and craft objects in a grid world.  

* **Program structure** – A `program` consists of a `stmt_seq`, a possibly empty sequence of statements separated by semicolons.  

* **Statements** – The language provides three families of statements:  

  1. **Primitive actions** that directly affect the agent:  
     * `MOVE(direction)` – step one cell in the given cardinal direction.  
     * `TURN(turn_dir)` – rotate 90° left or right.  
     * `PICKUP(primitive)` – collect a resource that lies on the current cell.  
     * `USE_TOOL(tool)` – employ a tool that the agent already possesses.  
     * `CRAFT(item, workshop)` – combine resources at a specific workshop to produce an item.  
     * `WAIT` – consume a time step without changing the state.  

  2. **Navigation helper**:  
     * `GO_TO(target)` – high‑level navigation that automatically moves the agent to the nearest cell containing the specified `target`, which may be a primitive resource or a workshop. This abstracts away low‑level path‑finding.  

  3. **Control‑flow constructs** that enable adaptive programs:  
     * `IF(cond) … ENDIF` – execute the enclosed block once when the Boolean condition `cond` holds.  
     * `WHILE(cond) … ENDWHILE` – repeat the block while the condition remains true.  
     * `REPEAT … UNTIL(cond)` – execute the block at least once and stop when the condition becomes true.  

* **Conditions** – Boolean expressions (`cond`) can query the agent’s current state:  
  * `HAS_PRIMITIVE(p)` – true if the agent’s inventory already contains primitive `p`.  
  * `HAS_ITEM(i)` – true if the inventory contains crafted item `i`.  
  * `AT_WORKSHOP(w)` – true when the agent stands on a cell belonging to workshop `w`.  
  * Logical operators `NOT`, `AND`, `OR` combine sub‑conditions, and literals `TRUE` / `FALSE` are also permitted.  

* **Parameter enumerations** – The grammar enumerates all admissible values for directions, turn directions, primitives, items, tools, and workshops, matching exactly the domain’s definitions.  

* **Lexical tokens** – Punctuation symbols (`;`, `(`, `)`, `,`) are defined as single‑character terminals (`SEMICOLON`, `LPAR`, `RPAR`, `COMMA`). All other keywords (`MOVE`, `TURN`, `IF`, …) appear directly in productions as terminal function names.  

Together, these extensions give the synthesis engine the ability to write programs that react to the world, repeat actions until resources are gathered, and navigate without hard‑coding exact paths, thereby addressing the previously identified failure modes.- **MOVE(direction)** – Move the agent one cell north, south, east or west.  
- **TURN(turn_dir)** – Rotate the agent 90° left or right.  
- **PICKUP(primitive)** – Collect the specified primitive resource from the current cell.  
- **USE_TOOL(tool)** – Use a tool that the agent already carries (e.g., axe, hammer).  
- **CRAFT(item, workshop)** – Combine required resources at the given workshop to produce the specified item.  
- **WAIT** – Do nothing for one time step.  
- **GO_TO(target)** – Automatically navigate to the nearest cell containing the given primitive or workshop.  
- **IF(condition) … ENDIF** – Execute the enclosed block once if the Boolean condition holds.  
- **WHILE(condition) … ENDWHILE** – Repeatedly execute the block while the condition is true.  
- **REPEAT … UNTIL(condition)** – Execute the block at least once and stop when the condition becomes true.
