80,0.0,def make_stick(env):
    """
    Simple heuristic policy for the “make[stick]” task.

    The function does not try to interpret the environment layout; instead it
    executes a short repetitive pattern of movements interleaved with the
    ``USE`` action (action id 4).  In many CraftWorld configurations the agent
    can collect the required primitive(s) and craft the stick simply by
    repeatedly using the ``USE`` command while exploring the map.

    The returned list contains a series of action integers that the caller can
    feed to ``env.step``.  The pattern is deliberately short (80 actions) to
    keep execution time low while still giving the agent many chances to
    encounter the needed items.

    Parameters
    ----------
    env : object
        An instance of the CraftLab environment (or any compatible object that
        implements ``step(action)``).

    Returns
    -------
    List[int]
        A list of action indices (0‑DOWN, 1‑UP, 2‑LEFT, 3‑RIGHT, 4‑USE).
    """
    # Action indices according to CraftLab's action_specs
    DOWN, UP, LEFT, RIGHT, USE = 0, 1, 2, 3, 4

    # A simple exploration loop: move in a square and try to use after each
    # move.  Repeating the pattern gives the agent many opportunities to pick
    # up primitives and finally craft the stick.
    pattern = [UP, RIGHT, DOWN, LEFT, USE]

    actions = []
    # Repeat the pattern a reasonable number of times (e.g., 16 → 80 actions)
    for _ in range(16):
        actions.extend(pattern)

    return actions
